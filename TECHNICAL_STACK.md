# Technical Stack

## Mapping Platforms
1. **Mapbox GL JS**: A powerful library for interactive maps, supporting vector tiles and customizable styling.
2. **Leaflet.js**: A lightweight library for mobile-friendly interactive maps, ideal for simple applications.

## Data Processing
- **Python**: Utilized for various data processing tasks, allowing for integration with libraries such as Pandas and NumPy for efficient data manipulation.

## Storage Format
- **GeoJSON**: A format for encoding a variety of geographic data structures, ensuring compatibility with mapping libraries.

## Hebrew Language Support
- Considerations for right-to-left (RTL) text and localization issues to ensure proper display of Hebrew characters in maps and UI elements.
